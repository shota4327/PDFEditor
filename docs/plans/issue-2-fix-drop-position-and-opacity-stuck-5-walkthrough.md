# Issue #2 追加改修（第5フェーズ）：ドロップ位置不一致および半透明スタック不具合の解消 検証報告書（Walkthrough）

## 1. 実施概要
ユーザーからのフィードバックにより判明した以下の2点の不具合を解消しました：
1. **表示とドロップ位置の不一致**: ドラッグ中の画面表示とマウスを離した後の最終配置位置がずれる場合がある（元のサムネイルより外側まで大きく動かさないと判定されない）。
2. **ドロップ後の半透明スタック**: ドロップ終了後、カードが半透明（ドラッグ中状態）のまま戻らなくなる場合がある。

---

## 2. 実施した変更内容

### 2.1 原因の特定と設計の改善
1. **ドロップ位置不一致**:
   - `handleDragEnd` 内で `onReorder` が二重に呼び出されていたため、`handleDragOver` でリアルタイムに移動した位置がドロップ瞬間に別位置や元位置へ再計算・上書きされていました。
   - `customCollisionDetection` が `pointerWithin`（ポインターがカード内にあるか）を最優先していたため、カーソルが隣のカードの境界を完全に超える（外側に出る）まで当たり判定が発生しませんでした。
   - **対策**:
     - `handleDragEnd` 内での `onReorder` 呼び出しを完全排除し、ドラッグ中に画面上で見ていた位置がそのまま 100% 確実に最終位置となるよう確定化。
     - 衝突判定を `closestCenter` に変更し、カードを中心点方向へ半分動かした時点でスムーズかつ直感的にスロットが入れ替わるように改善。
     - `onDragCancel` を実装し、ドラッグ中断時に開始前順序へ安全に復帰するガードを追加。
2. **半透明スタック**:
   - `<DragOverlay dropAnimation={{ duration: 150, easing: 'ease' }}>` のアニメーション遅延中に `activeId` が null になり、`useSortable` 内部の `isDragging` がリセットされず `true` のままフリーズしていました。
   - **対策**:
     - `ThumbnailGrid` から `SortableThumbnailCard` へ `isDragging={activeId === page.id}` を明示的に渡し、親の状態と半透明スタイル（`opacity`）を厳密に一元同期。
     - `<DragOverlay dropAnimation={null}>` に設定し、マウスを離した瞬間に不要な遅延なく即座に全カードを通常表示（`opacity: 1`）へ復帰。
