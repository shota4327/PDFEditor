# Issue #2 ページ読み込み後のページコンテナ廃止 実装計画書

PDFページのサムネイル表示カード（`ThumbnailCard`）における上下の固定バー（ページコンテナ）を廃止し、サムネイル領域そのものをカードの基本として、各操作・情報要素をライト半透明の角丸ピルバッジとしてフローティング配置するモダンでスッキリとした UI へ刷新します。

## ユーザー確認事項（確定済み要件）

事前インタビュー（`/grill-me`）により、以下の設計方針で合意済みです：
- **表示タイミング**: 常時半透明（`bg-white/75 backdrop-blur-md`）のピルバッジとして表示。
- **ドラッグ＆ドロップ（DND）**: 専用グリップアイコンは廃止し、カード全体（ボタン等の操作要素以外）をつかんで並び替え可能にする。
- **上部配置**: 左上にタイトル（長文は省略表示）、右端に削除ボタン（`Trash2`）。
- **下部配置**: 左下に「回転量（例: `0°`）＋ 反時計回り(CCW) ＋ 時計回り(CW)（アイコンのみ）」を1つのピルバッジにまとめて配置。右下にページ番号（「`1 / 5`」形式）を配置。
- **外枠スタイリング**: サムネイル領域そのものをカード本体とし、角丸・極細枠線・ドロップシャドウ（ホバー時の浮き上がりやドラッグ中の強調）を保持。
- **配色テーマ**: 白地のPDFでも視認性が高くモダンな「ライト半透明（`bg-white/75 backdrop-blur-md` ＋ 濃色文字/アイコン ＋ 極細白枠 ＋ 影）」。

## 変更予定コンポーネント

### 1. UI コンポーネント (SRP 原則 & 30〜50行目安遵守)

- `src/components/ThumbnailCard.tsx`:
  - 上下の固定ヘッダー・フッターバーの配置を廃止。
  - `totalPages?: number` をプロパティに追加。
  - カード本体をサムネイルプレビュー領域とし、その中に上部・下部フローティングオーバーレイを配置。
- `src/components/ThumbnailCardHeader.tsx`:
  - 旧上部バーから、サムネイル上部に浮かぶ「左上のタイトルピル」および「右端の削除ボタンピル」から成るオーバーレイコンポーネントへ刷新。
  - `data-testid="file-name"`, `data-testid="delete-page-btn"` を維持。
- `src/components/ThumbnailCardFooter.tsx`:
  - 旧下部バーから、サムネイル下部に浮かぶ「左下の回転コントロールピル（角度表示 ＋ CCWボタン ＋ CWボタン）」および「右下のページ数ピル（`1 / N`）」から成るオーバーレイコンポーネントへ刷新。
  - `data-testid="rotation-badge"`, `data-testid="rotate-ccw-btn"`, `data-testid="rotate-cw-btn"`, `data-testid="page-number"` を維持。
- `src/components/ThumbnailPreview.tsx`:
  - 旧レイアウトの内部固定バッジ（左上の `Page X`、右下の `0°`）を整理し、純粋なサムネイル描画とリサイズ追従の責務に特化。
- `src/components/ThumbnailGrid.tsx`:
  - `ThumbnailCard` に `totalPages={pages.length}` を伝達。
