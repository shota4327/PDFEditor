# Issue #2 追加改修：プレビュー画像の完全カード化と余白排除・半透明グレー基調への刷新 実装計画書

ユーザーからのフィードバックに基づき、プレビュー画像背後の灰色エリアを完全廃止し、プレビュー画像自体をカードとして外枠・影・角丸を密着適用します。また、ズーム時の左右余白を排除するためフレックス配置へ移行し、ボタン・バッジを半透明ライトグレー基調に刷新します。

## ユーザー確認事項（確定済み要件）

事前インタビュー（`/grill-me`）により、以下の設計方針で合意済みです：
- **プレビュー自体のカード化**:
  - `ThumbnailPreview` の背景色（`bg-slate-200/70` 等の灰色）を完全撤廃。
  - 余白ゼロでプレビュー画像そのものに角丸・枠線・影（ホバー/ドラッグ効果）を適用し、画像とカード枠を完全密着。
- **ズーム変更時の左右余白排除**:
  - `ThumbnailGrid` の `1fr` による横幅引き延ばしグリッドを廃止し、`flex flex-wrap gap-4 items-start`（左寄せ・自然な折り返し）へ移行。
  - `ThumbnailCard` は画像の自然な縦横比（Aspect Ratio）に合わせて幅を決定し、余分な左右の余白を完全排除。
- **90度回転時の外形密着**:
  - 90度・270度回転時は、カード自体の縦横比も反転させ、回転後のプレビュー画像に完全に密着（余白ゼロ）させる。
- **半透明グレー基調のボタン・バッジ**:
  - ライトグレー半透明（`bg-slate-300/70 backdrop-blur-md` ＋ 濃色文字/濃色アイコン `text-slate-800` ＋ 極細境界線 `border-white/40`）を採用。

## 変更予定コンポーネント

### 1. UI コンポーネント (SRP 原則 & 30〜50行目安遵守)

- `src/components/ThumbnailPreview.tsx`:
  - 背景色（`bg-slate-200/70`）および内部余白（`p-1.5`）を撤廃。
  - 画像のアスペクト比を読み込み、0°/180° および 90°/270° の回転角度に応じてプレビュー幅・高さを正確に算出し、カード枠内にピタリとフィットさせる。
- `src/components/ThumbnailCard.tsx`:
  - カードコンテナの不要な背景色や固定余白を撤廃し、プレビュー画像の縦横サイズに密着（`w-fit` / インラインサイズ）。
  - 角丸（`rounded-lg`）、枠線（`border border-slate-200`）、影（`shadow-sm hover:shadow-md`）、ドラッグ強調効果をプレビュー枠に直接適用。
- `src/components/ThumbnailGrid.tsx`:
  - `display: grid`（`minmax(..., 1fr)`）から `display: flex; flex-wrap: wrap; gap: 1rem;` へ変更し、列幅の無理な引き延ばしによる左右余白を完全解消。
- `src/components/ThumbnailCardHeader.tsx`:
  - ファイル名ピルおよび削除ボタンの配色を「半透明ライトグレー（`bg-slate-300/70` ＋ `text-slate-800`）」へ更新。
- `src/components/ThumbnailCardFooter.tsx`:
  - 回転コントロールピルおよびページ数ピルの配色を「半透明ライトグレー（`bg-slate-300/70` ＋ `text-slate-800`）」へ更新。
